# 统一测试题

规则：同一条提示词分别交给 Kimi K3.1 Pro、Claude Opus 5.5、Gemini（注明版本），各跑一次，不手动改代码；只允许一条追加消息「修复报错」（记为非一次通过）。输出必须是单个 HTML 文件，可用 CDN。记录耗时与 API 成本。

评分（/10）：能运行 2 · 玩法完整 3 · 手感/表现 3 · 视觉 2。

## 1. 平台跳跃
```
Create a complete 2D platformer game in a single HTML file using canvas. Include: a player with run, jump (variable height) and coyote time; 3 levels with platforms, spikes, moving platforms and collectible coins; a goal flag per level; a HUD with coins, lives and level; keyboard (arrows/WASD + space) and touch controls; a start screen and a win screen. No external assets; draw everything with code.
```

## 2. 弹球
```
Create a playable pinball game in a single HTML file. Include: two flippers (left/right keys or Z and /), a plunger launch (hold space), stable ball physics with no tunneling, at least 3 bumpers, 2 slingshots, a ramp or lane that awards bonus points, score and ball count (3 balls), tilt warning, and a game over screen with restart. No external assets.
```

## 3. 体素小岛
```
Create an interactive 3D voxel island in a single HTML file using three.js from a CDN. Include: a procedurally generated island with sand, grass, rocks, trees and water; a day/night cycle with sun and moon lighting and shadows; orbit camera controls; the ability to place and remove voxels with mouse clicks; and a small FPS counter. Keep it above 50 FPS on a laptop.
```

## 4. 卡牌抽卡特效
```
Create a gacha card-pull screen in a single HTML file. Include: a "Pull x1" and "Pull x10" button; rarities N, R, SR, SSR with probabilities 60/30/8/2 percent; a card-flip animation; distinct reveal effects per rarity (SSR gets a light burst, particles, screen shake and a golden glow); a 10-pull results grid revealed one by one with a skip button; a pity counter that guarantees SSR at 90 pulls; and a history panel. Draw card art with CSS/canvas, no external images.
```

## 5. 塔防
```
Create a tower defense game in a single HTML file using canvas. Include: a grid map with a fixed enemy path; 3 tower types (fast single-target, slow splash, slowing) with upgrade and sell; 10 waves of increasing difficulty including a boss wave; enemies with health bars; gold and lives; a start-wave button and 2x speed toggle; and win/lose screens. No external assets.
```
