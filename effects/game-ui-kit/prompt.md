## 第 1 轮（主提示词）

```
请只输出一个完整的 index.html 文件（内联 CSS 与 JavaScript），打开即可运行，不依赖任何付费服务或后端；界面文字全部用中文；添加 `<link rel="icon" href="data:,">` 避免 favicon 404；控制台不能有报错。

用纯 HTML + CSS + 原生 JS 做一套奇幻 RPG 风格的「游戏 UI 套件」演示页（深紫背景，金棕色描边面板，统一按钮样式带悬停发光）：
1. 主菜单：全屏遮罩，标题「星落之境」（金色发光、上下漂浮动画），按钮：开始游戏、继续冒险、设置、关于；「设置」弹出面板（主音量/音效滑块、画质下拉、显示伤害数字开关、保存）。点开始后淡出。
2. 角色 HUD（左上）：圆形头像 + 等级徽章、名字职业、生命条（红）、法力条（蓝）、经验条（金）；数值文字居中；扣血时有一层白色「延迟条」稍后才缩短；生命低于 25% 时血条闪烁。
3. 技能栏（底部居中）：6 个技能格（emoji + 快捷键数字），点击或按 1-6 消耗 40 法力并 toast 提示，法力不足提示「法力不足」。
4. 背包（右上，按 B 开关）：标题栏+关闭、分类标签（全部/装备/消耗/材料）、6 列 × 5 行格子，物品按稀有度描边（蓝/紫/橙发光），堆叠数量角标；悬停显示跟随鼠标的提示框（名字按稀有度着色、属性）；支持 HTML5 拖拽交换格子；双击生命药水回血并减少数量；底部显示金币、钻石、容量。
5. 对话框（底部，按 T）：左侧头像框、说话人名字、打字机逐字显示（点击跳过）、▼ 继续提示；第二句给出 3 个选项（接受任务 → toast + 加经验；询问报酬；离开）。
6. 左下调试按钮：受到伤害（屏幕抖动）、治疗、背包、对话、主菜单（Esc）。
7. URL 参数 ?demo=1：跳过主菜单、打开背包、显示带选项的对话、生命设为 42%。
```
