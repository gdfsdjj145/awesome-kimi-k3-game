```
请用一个单独的 HTML 文件（内联 CSS + 原生 JavaScript，不依赖任何外部库或付费服务）做一个「卡牌十连抽」抽卡动画页面，界面文字全部用中文。

要求：
1. 主界面：深紫色星空径向渐变背景，全屏 Canvas 画闪烁的星星；标题「✦ 星辰祈愿 ✦」；两个圆角按钮「单抽」「十连抽」（十连抽为金橙渐变）；下方显示「累计 N 抽 · 距保底 M」。
2. 概率：五星 1.6%、四星 13%、其余三星；90 抽必出五星（硬保底）；十连里没有四星及以上时，最后一张强制换成四星。卡池用 emoji + 名字：五星 3 个（🐉苍龙·烛照、🔥焰之女帝、⚡雷霆剑圣），四星 4 个，三星 5 个。
3. 抽卡动画：点十连后隐藏主界面，10 张卡背朝上以 5×2 网格依次从上方落入（每张间隔约 120ms，CSS 3D transform）。卡背是斜条纹 + ✦。翻开前就有「预兆」：四星卡背发紫光，五星卡背发金光并脉动。
4. 翻牌：点击单张卡用 rotateY(180deg) 翻开（backface-visibility:hidden 双面卡）。正面按稀有度着色：三星蓝、四星紫且有光晕、五星金色并有多层金色 box-shadow，背后还有一圈旋转的 conic-gradient 光环（模糊）。按空格或点底部提示文字可依次全部翻开（每张间隔 90ms）。
5. 出金光效：本次十连含五星时，开场全屏金色径向闪光一次 + 屏幕中心金色粒子爆发；每翻开一张五星再爆一次金色+白色粒子并轻闪屏；四星爆紫色粒子，三星少量蓝色粒子。粒子画在背景 Canvas 上，用 'lighter' 混合，带重力和衰减。
6. 结算界面：全部翻开约 1 秒后弹出半透明毛玻璃遮罩「祈愿结算」，按稀有度从高到低排列 10 个小卡片，下面统计「五星 X · 四星 Y · 三星 Z」，有五星时加「🎉 恭喜出金！」；按钮「再来十连」「返回」。
7. 支持 URL 参数 ?demo=1：自动十连并在 1.5 秒后全部翻开，方便截图。
```
