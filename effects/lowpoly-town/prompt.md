## 第 1 轮（主提示词）

```
请只输出一个完整的 index.html 文件（内联 CSS 与 JavaScript），打开即可运行，不依赖任何付费服务或后端；界面文字全部用中文；添加 `<link rel="icon" href="data:,">` 避免 favicon 404；控制台不能有报错。

用一个 HTML 文件，通过 importmap 从 jsDelivr 引入 three@0.160.0 和 OrbitControls，做一个低多边形（flatShading）小镇：
1. 地形：半径约 36 的圆柱形草地岛，顶点 Y 轻微随机起伏；十字交叉的灰色道路，白色虚线。
2. 房屋（约 14 栋，分布在四个象限）：随机尺寸的方块墙体（5 种柔和墙色）+ 四棱锥屋顶（4 种颜色，按墙体比例缩放）+ 门 + 两扇窗（共用发光材质）+ 部分有烟囱；房子朝向道路。
3. 树：外圈约 45 棵 + 池塘边 10 棵；两种造型：两层圆锥松树、二十面体圆树（少量秋天橙色）。一个蓝色半透明池塘、一座钟楼。
4. 12 盏路灯（灯杆+发光球+PointLight），4 辆小车在双向车道上来回行驶（循环），8 朵由二十面体组成的白云缓慢飘动。
5. 用确定性伪随机（种子）生成，可以「重新生成」换种子。
6. 光照：半球光 + 投影的平行光（PCFSoftShadowMap）；按钮「切换白天/夜晚」：夜晚天空深蓝、太阳变弱蓝、窗户与路灯球发光、路灯 PointLight 点亮；雾颜色同步天空色。
7. OrbitControls：阻尼、默认自动环绕（按钮可开关）、限制俯仰和缩放距离。URL 参数 ?night=1 直接进入夜晚。左上角半透明面板显示操作说明与三个按钮。
```

## 第 2 轮（后期增强：辉光 + 震屏）

```
Three.js 场景：用 EffectComposer（RenderPass → UnrealBloomPass → OutputPass）替换 renderer.render；Bloom 受同一个「✨辉光」开关控制（关闭时直接 renderer.render），连续低帧时把渲染像素比乘 0.8（下限 0.6），并在尺寸或像素比变化时同步 composer 尺寸。右下角同样有 FPS 与辉光/震屏开关（场景类没有震屏时机，震屏开关保留但不触发）。
本效果的具体改动：加 UnrealBloom（阈值 0.75；夜晚强度 0.95，白天 0.25），路灯与车灯在夜里会发光晕。
```
