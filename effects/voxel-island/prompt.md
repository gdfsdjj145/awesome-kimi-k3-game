# 体素小岛 · 提示词

> **参考实现**：本效果由 Grok Bot 代 kajian du 制作，**不是 Kimi 生成**。提示词写成可以直接喂给 Kimi K3.1 Pro 复现同类效果的形式。

## 第 1 轮（主提示词）

```
请用一个单独的 HTML 文件，通过 importmap 从 jsDelivr CDN 引入 three@0.160.0（three.module.js 和 examples/jsm/controls/OrbitControls.js），做一个「体素小岛」场景，界面文字用中文。

1. 地形：半径 16 的圆形小岛，用两层值噪声（自己写 hash + 平滑插值，不用外部库）乘以 (1 - d²) 衰减得到每列高度（最高约 12 格）。方块类型：顶层高度 ≤1 是沙子，≥7 是石头，≥9 是雪，其余是草；草下 2 层是泥土，再往下是石头。
2. 树：在高度 2~6 的草地上按哈希随机（约 2.5% 概率）种树，3 格木头树干 + 十字/菱形的树叶团。
3. 性能：每种方块类型一个 InstancedMesh（BoxGeometry 1×1×1 + MeshLambertMaterial 纯色），开启投射与接收阴影。
4. 水面：200×200、120×120 分段的平面，放在 y=0.7，MeshPhongMaterial 半透明蓝色、flatShading、高光；每帧用两组 sin/cos 让顶点高度起伏形成波浪。
5. 相机：PerspectiveCamera 斜上方俯视，OrbitControls 开启阻尼，限制最大俯仰角（不能钻到水下）、最小/最大缩放距离。拖动旋转、滚轮缩放、右键平移。
6. 昼夜变化：时间 tod 从 0 到 1 循环，默认 60 秒一天（0=午夜，0.5=正午）。太阳（DirectionalLight + 投影 + 一个不受雾影响的黄色球体）和月亮（淡蓝弱光 + 白色球体）绕岛对向公转。天空背景色和雾颜色在夜晚深蓝、白天天蓝之间插值，日出日落时混入橙色。白天太阳亮、半球光亮；夜晚出现 1500 颗星星（Points，透明度随夜色增加），岛中心一盏暖色点光源亮起，水面颜色变暗。
7. 左上角半透明面板：标题提示操作，显示当前时间 HH:MM，一个「流速」滑块（0~3 倍），一个「暂停昼夜」复选框。
8. 支持 URL 参数 ?t=0.3 指定起始时间，方便截图白天/夜晚。窗口大小变化时自适应。
```

## 第 3 轮（后期增强：辉光 + 震屏）

```
Three.js 场景：用 EffectComposer（RenderPass → UnrealBloomPass → OutputPass）替换 renderer.render；Bloom 受同一个「✨辉光」开关控制（关闭时直接 renderer.render），连续低帧时把渲染像素比乘 0.8（下限 0.6），并在尺寸或像素比变化时同步 composer 尺寸。右下角同样有 FPS 与辉光/震屏开关（场景类没有震屏时机，震屏开关保留但不触发）。
本效果的具体改动：加 UnrealBloom（强度 0.45、半径 0.4、阈值 0.82），夜晚的灯光与日出更有氛围。
```
