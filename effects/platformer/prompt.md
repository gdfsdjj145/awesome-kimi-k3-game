# 平台跳跃 · 提示词

> **参考实现**：本效果由 Grok Bot 代 kajian du 制作，**不是 Kimi 生成**。下面的提示词写成可以直接喂给 Kimi K3.1 Pro（或其他模型）复现同类效果的形式，欢迎用 Kimi 跑一遍后提交对比结果。

## 第 1 轮（主提示词）

```
请只输出一个完整的 index.html 文件（内联 CSS 与 JavaScript），打开即可运行，不依赖任何付费服务或后端；界面文字全部用中文；添加 `<link rel="icon" href="data:,">` 避免 favicon 404；控制台不能有报错。

用原生 Canvas 2D 做一个横版平台跳跃小游戏：
1. 关卡用字符串数组描述（40px 一格）：`#` 地面（顶部自动画草皮）、`=` 半高木平台、`^` 尖刺、`o` 金币、`E` 敌人、`F` 终点旗；关卡约 82 列 × 11 行，含坑、尖刺、高低平台，一直延伸到终点。
2. 角色：红色方块小人（白眼睛），← → / A D 加速移动（带摩擦），空格/↑/W 跳跃，支持二段跳；起跳挤压、落地回弹（scale 动画）；跳跃时脚下扬尘粒子。
3. 物理：重力 0.55、最大下落 14；先移动 X 再按格子做 AABB 碰撞，再移动 Y 碰撞；注意碰到一格后立刻 return，不要在同一帧里继续用已清零的速度判断；每帧用脚下 1px 检测是否站在地面，避免「站地/离地」交替闪烁导致不能跳。
4. 敌人：紫色史莱姆左右巡逻，碰墙或到平台边缘掉头；从上方踩（下落中且脚底与敌人顶部差 <16px）消灭并弹起 +50 分，其余接触扣命。
5. 金币旋转（椭圆宽度随时间 cos 变化），吃到 +10 并冒金色粒子；碰尖刺或掉出地图扣 1 命并重开关卡，3 命用完分数清零；到达旗帜显示「🎉 通关！按 R 重来」。
6. 镜头平滑跟随（lerp 0.1），背景天蓝渐变 + 视差绿色山丘；左上角 HUD：❤️ 命数、🪙 分数、操作提示。
7. URL 参数 ?demo=1：自动向右跑，前方是坑/尖刺/墙时自动跳，演示中踩敌人视为消灭（方便截图）。
```

## 修改记录

- 第 1 轮：按上面的主提示词一次写完全部功能。
- 第 2 轮：修复碰撞——同一帧多格碰撞时速度已清零导致角色被弹到地下；改为命中第一格后 return。
- 第 3 轮：加脚下 1px 着地检测，修复站立时 on 标志闪烁；演示模式改为按前方地形自动跳。

## 第 4 轮（后期增强：辉光 + 震屏）

```
在现有效果基础上只加后期，不改玩法：在 <body> 开头加入一个内联小工具（全局对象 FX）：①低分辨率辉光——每帧在游戏自己绘制完之后，把主画布缩小到 1/4（省电档 1/5）绘制到离屏 Canvas，用 ctx.filter「brightness + contrast + saturate」近似提取亮部（不支持 ctx.filter 的浏览器改用 getImageData 手动阈值），再以 lighter 混合、约 0.8 透明度放大叠回主画布（若画布本身用半透明覆盖做拖尾，则改为叠在画布上方的独立 canvas，mix-blend-mode: screen，避免反馈累积）；②震屏——FX.shake(强度) 给目标元素设置 CSS translate 随机偏移并按 0.86 衰减（用独立的 translate 属性，不覆盖原有 transform）；③右下角小工具栏显示 FPS，「✨辉光」「📳震屏」两个开关，状态存 localStorage，URL 参数 ?noglow / ?noshake 可关闭；④连续 2 秒低于 40 FPS 自动把辉光分辨率降到 1/6、1/8；触屏/小屏/低核数设备进入省电档。画布原本就是 1 倍像素（DPR ≤ 2 已满足）。
本效果的具体改动：只加震屏不加辉光：踩敌 FX.shake(4)，死亡 FX.shake(12)。理由：白天亮色天空背景加辉光会整体发白，破坏原有像素风。
```
