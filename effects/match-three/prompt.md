## 第 1 轮（主提示词）

```
请只输出一个完整的 index.html 文件（内联 CSS 与 JavaScript），打开即可运行，不依赖任何付费服务或后端；界面文字全部用中文；添加 `<link rel="icon" href="data:,">` 避免 favicon 404；控制台不能有报错。

用 Canvas 2D（480×480，8×8 格）做一个三消游戏：
1. 6 种宝石用 emoji：🍎🍋🍇🍀💎🍊；开局生成时保证没有现成的三连，宝石从上方掉落入场。
2. 操作：点选一个再点相邻格交换，或按住拖向相邻方向交换；选中宝石放大并上下浮动。
3. 交换动画 200ms；若没有形成三连则自动换回；形成则步数 -1，进入结算循环：找出所有横竖 ≥3 连 → 宝石缩小消失 + 彩色粒子 + 飘字「+分数」（连锁时显示「连击×N」）→ 上方宝石下落、顶部补新宝石（缓动下落）→ 继续检测直到没有可消。分数 = 消除数 × 10 × 连击数，连击时轻微屏幕震动。
4. 顶部胶囊 HUD：⭐ 得分、👣 剩余步数（30）、🔥 连击；步数用完飘字显示最终分数；「重新开始」按钮。
5. 背景粉紫渐变，棋盘半透明白底圆角。注意：Canvas 绘制 emoji 前要把 fillStyle 设为不透明颜色，否则 emoji 会继承半透明 fillStyle 变淡。
6. URL 参数 ?demo=1：1.2 秒后自动找一个能消的交换并执行。
```
