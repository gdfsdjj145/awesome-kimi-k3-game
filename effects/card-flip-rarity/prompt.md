## 第 1 轮（主提示词）

```
请只输出一个完整的 index.html 文件（内联 CSS 与 JavaScript），打开即可运行，不依赖任何付费服务或后端；界面文字全部用中文；添加 `<link rel="icon" href="data:,">` 避免 favicon 404；控制台不能有报错。

做一个「稀有度图鉴」页面，展示 5 张不同稀有度的卡牌：
1. 稀有度与配色：N 普通（灰）、R 稀有（蓝）、SR 史诗（紫）、SSR 传说（金）、UR 神话（粉+彩虹）。每张卡 180×260，正面有稀有度胶囊标签、大 emoji 立绘（带同色 drop-shadow）、名字、星级、描述。
2. 点击用 CSS 3D rotateY(180deg) 翻转（backface-visibility 双面，弹性贝塞尔曲线）；翻开后鼠标悬停时卡片随鼠标做 3D 倾斜。
3. 分级光效：SR 紫色外发光；SSR 金色多层 box-shadow + 背后旋转的 conic-gradient 金色光环（模糊）+ 斜向扫光动画；UR 在此基础上加彩虹全息层（mix-blend-mode: color-dodge，渐变角度随鼠标位置变化）和炫彩旋转光环。
4. 翻开 SR 及以上时，在全屏 Canvas 上从卡片中心爆发对应颜色的粒子（数量随稀有度增加，lighter 混合），UR 额外全屏白光闪一下。
5. 底部按钮：全部翻开（依次间隔 250ms）、全部盖回、随机洗牌。深色背景，标题「✦ 稀有度图鉴 ✦」。
6. URL 参数 ?demo=1：自动全部翻开。
```

## 第 2 轮（后期增强：辉光 + 震屏）

```
在现有效果基础上只加后期，不改玩法：在 <body> 开头加入一个内联小工具（全局对象 FX）：①低分辨率辉光——每帧在游戏自己绘制完之后，把主画布缩小到 1/4（省电档 1/5）绘制到离屏 Canvas，用 ctx.filter「brightness + contrast + saturate」近似提取亮部（不支持 ctx.filter 的浏览器改用 getImageData 手动阈值），再以 lighter 混合、约 0.8 透明度放大叠回主画布（若画布本身用半透明覆盖做拖尾，则改为叠在画布上方的独立 canvas，mix-blend-mode: screen，避免反馈累积）；②震屏——FX.shake(强度) 给目标元素设置 CSS translate 随机偏移并按 0.86 衰减（用独立的 translate 属性，不覆盖原有 transform）；③右下角小工具栏显示 FPS，「✨辉光」「📳震屏」两个开关，状态存 localStorage，URL 参数 ?noglow / ?noshake 可关闭；④连续 2 秒低于 40 FPS 自动把辉光分辨率降到 1/6、1/8；触屏/小屏/低核数设备进入省电档。画布原本就是 1 倍像素（DPR ≤ 2 已满足）。
本效果的具体改动：粒子特效画布加辉光；翻开 SR/SSR/UR 时震动卡牌行，强度 4/7/10。
```
