## 第 1 轮（主提示词）

```
要求：只输出一个完整的 index.html 单文件，CSS/JS 全部内联（可用 jsDelivr CDN 的开源库，如 three@0.160 及其 examples/jsm 后期模块），不调用任何付费服务或 API；界面文字使用中文；<head> 中加入 <link rel="icon" href="data:,"> 避免 favicon 404；控制台不得有任何报错。
性能与移动端：viewport 设为 width=device-width 并禁止缩放；devicePixelRatio 上限 2；在触屏/小屏/低核数设备上自动进入「省电档」（粒子数减半）；右下角显示实时 FPS，若连续 2 秒低于 40 FPS 就自动降低渲染分辨率（WebGL）或粒子数（Canvas）；所有交互同时支持鼠标与触摸（pointer 事件，touch-action:none）。

做一个手游「SSR 传说级开包」动画：深色背景中央悬浮一个紫金色卡包（Canvas 绘制，带流光扫过）。点击后时间轴：0–1.2 秒蓄力（卡包抖动越来越剧烈，表面出现越来越多的发光裂纹，背后泛出稀有度颜色的光晕）；1.2 秒爆开（闪白、卡包碎片带重力飞散、三道彩色冲击环、数百个彩虹/金色粒子爆射）；随后背景出现旋转的放射光芒（SSR 为彩虹色），「SSR」斜体大字从 3 倍大小砸入并带金色渐变与外发光；2.0 秒起卡牌（DOM + CSS 3D，背面花纹）从上方落下，2.7 秒翻面（rotateY 180°，伴随第二次闪白），正面有渐变边框、卡面插画（Canvas 画的图案 + 大号 emoji）、名称栏和不断扫过的镭射高光。稀有度：开关「必出 SSR」，关闭时按 SSR 8% / SR 22% / R 70% 抽取，SR、R 的光效颜色与强度更弱。统计各稀有度次数，底部「再开一包」按钮。?t=1.6 冻结时刻截图，?demo=1 自动循环。
```
