# 技能释放特效 · 提示词

> **参考实现**：本效果由 Grok Bot 代 kajian du 制作，**不是 Kimi 生成**。提示词写成可以直接喂给 Kimi K3.1 Pro 复现同类效果的形式。

## 第 1 轮（主提示词）

```
请用一个单独的 HTML 文件（全屏 Canvas 2D + 原生 JavaScript，不依赖任何外部库）做一个「技能释放特效」演示，界面文字用中文。

场景：深色背景，下方 40% 是带透视斜线的地面。左边一个蓝色方块小人（英雄，身体矩形 + 圆头 + 椭圆阴影），右边一个棕色木桩（同样造型），木桩头顶有红色血条，血量打空后 0.8 秒回满。点击场景任意位置把木桩挪过去。

底部技能栏 4 个方形按钮（emoji 图标 + 名字 + 左上角快捷键数字 + 从下往上的冷却遮罩），按 1/2/3/4 或点击释放：
1. 🔥 火球术（CD 0.6s）：火球飞向木桩，沿途不断喷出橙黄火焰粒子，并画渐隐的圆形拖尾；命中时橙黄白三色粒子爆炸 + 扩散冲击环。
2. ⚡ 连锁闪电（CD 1.2s）：从英雄到木桩画 10 段随机折线闪电，外层粗蓝色半透明 + 内层细白色，0.3 秒内淡出；同时木桩处蓝白粒子爆炸。
3. 🗡️ 疾风斩（CD 0.8s）：高速飞出的绿色月牙剑气，拖尾是多道由淡到浓的弧线；命中绿白粒子。
4. ☄️ 陨石天降（CD 2.5s）：陨石从左上方斜向砸到木桩，沿途冒红黄灰烟火粒子，落地时 200 个粒子的大爆炸 + 冲击环，震动最强。

通用打击感：
- 粒子系统：位置/速度/重力/阻尼/寿命，半径随寿命缩小，globalCompositeOperation='lighter' 叠加发光。
- 受击闪白：木桩被打中后整体变白再快速衰减（flash *= 0.85），同时向后击退几像素；闪白很强时全屏叠一层很淡的白色。
- 屏幕震动：每次命中按技能强度设置 shake 值，每帧在 [-shake, shake] 内随机平移画布，shake *= 0.88 衰减。
- 伤害飘字：命中时木桩头顶飘出数字，30% 概率「暴击」为金色大字且伤害翻倍，黑色描边，上浮并淡出。
- 释放时英雄身上有一圈对应颜色的小粒子。
支持 URL 参数 ?demo=1：自动依次释放 4 个技能（间隔 350ms），方便截图。
```
